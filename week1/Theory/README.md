# Week 1 Theory: Microcontroller Fundamentals

Welcome to the theoretical foundation of IoT programming! This directory contains essential concepts and knowledge required for Week 1 projects and the entire summer school.

## 📚 Core Concepts Covered

### 1. **Microcontroller Basics**
- What is a microcontroller?
- Microcontroller vs. Microprocessor vs. Single Board Computer
- CPU, RAM, ROM, and I/O pins overview
- Clock speed and processing power
- Popular platforms: Arduino, PIC, STM32

### 2. **Arduino Platform**
- Arduino ecosystem and boards
- Arduino Uno specifications and pinout
- How to identify different pin types
- Power requirements and limitations
- USB communication for programming and debugging

### 3. **Digital I/O Fundamentals**
- Binary logic: HIGH (1) and LOW (0)
- Digital pins and their configuration
- Input vs. Output modes
- Pull-up and pull-down resistors
- Logic levels and voltage considerations (TTL 5V vs 3.3V)

### 4. **Analog I/O Concepts**
- Analog vs. Digital signals
- Analog-to-Digital Conversion (ADC)
- Resolution and accuracy
- Voltage reference and measurement range
- Analog pins (A0-A5 on Arduino Uno)

### 5. **PWM (Pulse Width Modulation)**
- PWM basics and wave characteristics
- Duty cycle and frequency
- Analog simulation using PWM
- PWM-capable pins on Arduino
- Applications: LED brightness, motor speed, sound generation

### 6. **Electrical Concepts for Microcontrollers**
- Voltage and current
- Ohm's Law (V = I × R)
- Power dissipation and heat management
- Pull-up and pull-down resistor networks
- Current limiting with resistors
- Protection circuits (diodes, capacitors)

### 7. **LED Operations**
- LED forward voltage and current requirements
- Calculating resistor values for LEDs
- Common cathode vs. common anode configuration
- RGB LEDs and color mixing
- LED matrix scanning

### 8. **Push Button/Switch Basics**
- Mechanical switch operation
- Contact debouncing and noise
- Button state detection
- Pull-up resistor configuration for buttons
- Debouncing techniques in software

### 9. **C++ Fundamentals for Embedded Systems**
- Variables and data types (int, float, boolean)
- Arrays and strings in embedded context
- Control structures (if-else, loops)
- Functions and code organization
- Memory considerations on microcontrollers

### 10. **Arduino Programming Environment**
- Arduino IDE overview
- Serial library for debugging
- digitalWrite() and digitalRead() functions
- analogWrite() and analogRead() functions
- delay() and timing functions
- Setup and loop structure

## 🎯 Learning Outcomes

By studying this theory section, you should understand:

✓ How microcontrollers work and their role in IoT systems
✓ The Arduino platform and its capabilities
✓ Digital and analog I/O concepts and applications
✓ Basic electrical principles needed for safe operation
✓ How to read and interpret pin diagrams and datasheets
✓ C++ syntax and programming patterns for embedded systems
✓ How to use the Arduino IDE and serial communication
