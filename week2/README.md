# Week 2: IoT Summer School 2026

Welcome to Week 2 of the IoT Summer School! This week covers essential microcontroller programming concepts and practical projects using C++.

## 📚 Learning Objectives

This week focuses on:
- Digital and Analog I/O operations
- PWM (Pulse Width Modulation)
- Serial communication and command interfaces
- I2C Protocol implementation
- Sensor integration and data processing
- Real-world IoT applications

## 📁 Projects Overview

### 1. **Gas Detector**
A practical implementation of a gas detection system using analog sensors.
- Reads analog sensor data
- Processes readings for safety thresholds
- Provides alarm/alert mechanisms

### 2. **I2C Protocol**
Deep dive into I2C (Inter-Integrated Circuit) communication protocol.
- Master-Slave communication
- Address selection and data transmission
- Multi-device coordination

### 3. **PWM Fading Night Light**
Create an adjustable lighting system using PWM control.
- Pulse Width Modulation fundamentals
- Brightness control through duty cycle adjustment
- Practical application of analog output simulation

### 4. **Serial Command Interface**
Build an interactive system controlled via serial communication.
- Serial UART communication
- Command parsing and execution
- Real-time feedback and monitoring

### 5. **Temperature Monitoring System**
Implement a complete temperature monitoring solution.
- Sensor integration (e.g., DHT sensors, thermocouples)
- Data acquisition and logging
- Temperature threshold alerts

### 6. **Traffic Light**
Simulate a traffic light control system with state management.
- LED control and sequencing
- Timing and state transitions
- Basic finite state machine implementation

### 7. **Vending Machine**
Create a vending machine simulator with coin/button logic.
- Input processing (buttons, sensors)
- State management for transactions
- Output control (motors, displays)

### 8. **Digital Piano**
Build a simple digital piano using buttons and speakers/buzzers.
- Frequency generation
- Tone synthesis
- Button-to-note mapping

### 9. **Theory**
Theoretical materials and foundational concepts for the week.
- Microcontroller architecture
- Digital and analog I/O basics
- Communication protocols
- Programming best practices

## 🛠️ Technical Stack

- **Language:** C++
- **Target Platform:** Microcontroller/Arduino-compatible boards
- **Key Concepts:** GPIO, PWM, Sensors, Serial Communication, I2C

## 🚀 Getting Started

1. Select a project directory
2. Review any theory materials in the `Theory` folder
3. Study the implementation files
4. Understand the circuit diagrams (if provided)
5. Compile and upload to your microcontroller
6. Experiment and modify!

## 📝 Notes

- All projects follow the same coding structure for consistency
- Each project includes necessary configuration for the target microcontroller
- Refer to datasheet documentation for component specifications
- Test incrementally - verify each component before integration

## 💡 Tips for Success

- Start with simpler projects (like Traffic Light) before complex ones
- Understand the theory before diving into implementation
- Use serial debugging output liberally
- Test sensors and components individually first
- Document your findings and modifications
